# Requisitos del modulo Cliente

## Objetivo

Permitir que el cliente consulte de forma clara los productos disponibles de la cafeteria.

## Requisitos funcionales

- El cliente puede visualizar el catalogo.
- Cada producto muestra nombre, precio, categoria y stock.
- El catalogo organiza los productos por categoria.
- El cliente puede filtrar productos por categoria.
- Los productos sin stock se identifican como agotados.
- La informacion se obtiene desde el backend.

## Alcance hasta la semana 6

Este documento corresponde a la actividad de planificacion y requerimientos del modulo Cliente. El alcance principal es la consulta del catalogo.
