# Diseno de datos y UI/UX del Cliente

## Estructura del producto

El catalogo utiliza los siguientes campos:

- `id`: identificador del producto.
- `nombre`: nombre visible para el cliente.
- `precio`: precio de venta.
- `stock`: cantidad disponible.
- `categoria`: grupo al que pertenece el producto.

## Interfaz del catalogo

La vista del Cliente se organiza en estas zonas:

1. Encabezado del panel Cliente.
2. Titulo y descripcion del catalogo.
3. Filtros por categoria.
4. Tarjetas de productos con precio y stock.
5. Indicador visual de disponibilidad.

## Criterio de usabilidad

La informacion principal debe poder identificarse rapidamente: nombre, categoria, precio y disponibilidad. Los filtros permiten consultar el catalogo sin recorrer productos de otras categorias.
